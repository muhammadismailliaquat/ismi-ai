AI Provider Fallback Chain

Resilient AI chatbot implementation with automatic provider switching

✅ Implemented TypeScript Next.js

Overview

This implementation adds a fallback chain to the Ismi.ai chatbot, ensuring users always get responses even when individual AI providers hit rate limits or experience outages. The system automatically tries providers in order until one succeeds.

Gemini

Model: gemini-pro

Env Var: GEMINI_API_KEY

- Quota exceeded
- Network errors

Groq

Secondary Provider

API: OpenAI-compatible

Model: llama-3.3-70b-versatile

Env Var: GROQ_API_KEY

// HTTP errors that trigger fallback:
- 429 Rate limit
- 402 Payment required
- 503 Service unavailable
O

OpenRouter

Tertiary Provider

API: OpenAI-compatible
